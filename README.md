# Jessica Moren — The Perimenopausal Princess

A four-page editorial author website built with Next.js, TypeScript, and Tailwind CSS.

## Pages

- `/` — Home
- `/books` — Book series and Book One details
- `/about` — About Jessica Moren
- `/contact` — Reader, press, podcast, and book-club inquiries

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run build
npm run lint
```

Retailer links, newsletter delivery, and contact-form delivery are intentionally awaiting author-approved destinations and service-provider configuration.
